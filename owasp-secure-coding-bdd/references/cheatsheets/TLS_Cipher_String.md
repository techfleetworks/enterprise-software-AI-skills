# TLS Cipher String (deprecated)

OWASP has deprecated the TLS Cipher String cheat sheet. Its guidance now lives in the Transport Layer Security
cheat sheet, so there is no separate control content or `@security` scenario here. This file is kept only as a
routing pointer so a search for "TLS cipher string" still lands somewhere useful.

Use the Transport Layer Security sheet for cipher-suite choice and TLS configuration controls:

- In this skill: [Transport Layer Security](references/cheatsheets/Transport_Layer_Security.md)
